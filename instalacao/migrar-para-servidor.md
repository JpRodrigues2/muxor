# Migrar do Mac para um servidor

**Em construção:** o comando `hub migrar servidor` vai levar a instalação local (espaços, projetos, regras e
credenciais) para um servidor seu. Até lá, instale o servidor pelo [modo servidor](modo-servidor.md) e, depois,
desinstale do Mac com `./muxor desinstalar` (o mesmo bot do Telegram pode ser usado no servidor: guarde o token).
