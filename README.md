# Muxor

Lê as suas tasks nas ferramentas de gestão (Funifier PM, Bnexo, Jira), manda a lista no Telegram e despacha as que
você escolher para sessões do Claude Code no Orca. Avisa quando a sessão termina ou precisa de você, e dá para
acompanhar e responder pelo celular.

- **Instalar e usar:** comece por [`instalacao/README.md`](instalacao/README.md).
- **Desinstalar:** [`instalacao/desinstalar.md`](instalacao/desinstalar.md).

Funciona no macOS (modo local) e em servidores Linux (modo servidor).
